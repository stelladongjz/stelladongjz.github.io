# Stella Dong - Academic Portfolio for PhD Application

## Overview
This is a comprehensive academic portfolio showcasing UX/UI design projects, research work, and academic contributions in Human-Computer Interaction. The portfolio is designed specifically for PhD applications and demonstrates expertise in design, research, and academic writing.

## Features

### 🎨 **Design Portfolio Section**
- Showcases UX/UI design projects with detailed descriptions
- Research areas and expertise highlights
- Design tools and methodologies
- Interactive project cards with hover effects

### 🔬 **Research Projects**
- Voice Interface Research
- Healthcare Design System
- Accessibility Design Audit
- Mobile App Redesign
- Design Thinking Workshops
- User Research Portfolio

### 🛠️ **Technical Skills**
- **Design Tools**: Figma, Adobe Creative Cloud, Sketch, InVision, Zeplin
- **Research Tools**: Miro, Notion, Jira, Google Analytics
- **Development**: React, JavaScript, Python, Node.js
- **Research Methods**: User Research, Usability Testing, Ethnographic Studies

### 📚 **Academic Focus**
- Human-Computer Interaction
- User Experience Design
- Accessibility & Inclusive Design
- Design Systems
- Voice & Conversational Interfaces
- Healthcare Technology Design

## Customization Guide

### 1. Personal Information
Update the following files with your specific information:
- `src/components/Home/Home.js` - Your name and title
- `src/components/About/AboutCard.js` - Your background and education
- `src/components/About/AboutCard.js` - Your location and specific details

### 2. Projects
Customize the projects in:
- `src/components/Projects/Projects.js` - General projects
- `src/components/DesignPortfolio/DesignPortfolio.js` - Design-specific projects

### 3. Skills & Tools
Update your skills in:
- `src/components/About/Techstack.js` - Technical skills
- `src/components/About/Toolstack.js` - Tools and software

### 4. Social Links
Update your social media and professional links in:
- `src/components/Footer.js` - Social media links
- `src/components/Navbar.js` - External links

### 5. Images & Assets
Replace placeholder images in:
- `src/Assets/` directory
- Update logo and profile images

## Project Structure

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm start
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

## Academic Portfolio Tips

### For PhD Applications
1. **Highlight Research Experience**: Emphasize your research methodology and findings
2. **Show Design Process**: Demonstrate your design thinking and problem-solving approach
3. **Quantify Impact**: Include metrics and measurable outcomes from your projects
4. **Academic Writing**: Showcase your ability to communicate research findings
5. **Interdisciplinary Skills**: Highlight how you bridge design and research

### Portfolio Content
- **Research Projects**: Detailed descriptions with methodology and outcomes
- **Design Work**: Process documentation and final deliverables
- **Academic Credentials**: Education, publications, and presentations
- **Professional Experience**: Industry work and collaborations
- **Skills Matrix**: Technical and soft skills relevant to HCI research
